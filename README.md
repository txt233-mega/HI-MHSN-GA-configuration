# HI-MHSN-GA-configuration
Genetic algorithm configuration and driver script for the HI-MHSN optimization described in the accompanying manuscript.

# GA Configuration for HI-MHSN Optimization

## Scope

This repository provides the genetic algorithm configuration and driver
script used for the optimization of the heat-integrated methanol hydrogen
supply network (HI-MHSN).

## Software requirements

- MATLAB R2023b
- Global Optimization Toolbox
